The cumulative Blacksite Zeta server update is active. This client includes every update since the Mekanism/GUI changes, all requested content mods, Create Nuclear, ore generation, and the Blacksite Star quest book.

- Removed Create Better FPS after the reported Create belt-registration startup crash.
- Increased Create's maximum RPM to 512.
- Enabled Voxy's local terrain collection, including the mining dimension, while preserving other preferences.
- Preserved FTB random/choice reward links with correctly typed SNBT IDs.
- The readable BAT verifies all 286 required mods plus four optional optimizations, repairs missing/wrong files, and applies configs, resources, quests and recipes. It creates no backups and preserves saves, maps and personal settings.

Existing profiles: close Minecraft and run the latest **Install-Blacksite.bat** below. This release needs installer version 2.

Fresh profiles: import **Blacksite-Complete-Client-Star-1.3.0.zip** into CurseForge. It bundles 285 required JARs and all client files; CurseForge or the BAT fetches Create Nuclear from its original author. Optional optimizations are fetched by the BAT. Use Minecraft 1.21.1, NeoForge 21.1.250 and Java 21.

New ores appear in newly generated chunks. Existing worlds, chunks and progress are preserved. Nether/End ore strata stay separate.
